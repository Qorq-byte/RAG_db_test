# 问答集合提示与切换验收

## 已确认范围

用户同意在问答输入框上方显示“当前提问集合：XXX”，并提供切换入口。本次实现无需离开问答页面即可通过选择框切换已有集合；没有集合时转到资料页引导创建。未选状态显示“当前提问集合：未选择”和“选择集合”。

集合名采用纯文本、可换行并提供完整提示。选择通过全局集合上下文同步顶部、侧栏、资料清单、检索、问答和任务页；资料页按UUID恢复选择，集合重命名后也能保持身份。切换到其他集合清空旧会话展示与引用，保留未发送草稿；已保存会话仍属于原集合。取消或确认同一个未变化的集合，不改变当前对话和重试上下文。

生成期间禁用切换按钮并在事件处理函数内防止直接调用。停止仍在等待后台结束时保持禁用。读取失败保留当前状态；确认时集合已消失则清除失效目标并提示重新选择。

# Codex式原生问答交互验收

## 交付范围

- 问题发送后立即显示在右侧消息块，助手回答在左侧逐步输出，保留深浅主题。
- 实时阶段包括检索、找到依据并连接模型、生成及保存；显示耗时，无虚构百分比或思考内容。没有证据时使用原有拒答逻辑。
- 原生多行输入框：Enter发送，Shift+Enter换行，中文输入法选词不误发。生成时可停止，失败/停止保留当前页面部分文本，提供重试。
- Ollama JSONL、OpenAI兼容SSE真实流式接口；增量每75毫秒合并刷新。协议必须完整结束才视作成功，限长/提前断流/格式错误不保存为完成答案。
- 服务明确拒绝流式时显示“非流式重试”，由用户主动触发；认证或限流失败不自动重试。非流式显示等待阶段，不能逐段展示正文。
- 支持安全Markdown、代码块、复制回答和每条回答的引用详情。禁止消息加载本地或远程资源、禁止原始HTML。历史会话恢复后仍能查看引用。
- 阅读历史时不强制滚到底部，可点“回到最新回答”。生成期间禁用集合/会话切换及新会话；请求身份校验拦截迟到事件。
- 关闭窗口时请求停止并等待后台结束，不销毁仍被使用的页面。完成后释放问答HTTP客户端。

## 使用与边界

源码入口仍为 `uv run ragdb-gui`，选择集合后打开“问答”。本次未使用真实DeepSeek或Ollama问答模型做联网生成验收；真实HTTP流验证使用本机合成服务，Ollama协议用分片回归覆盖。

停止为协作取消：检索/本地模型调用等待当前操作返回后处理；流式网络连接超时最多10秒、单次等待数据最多30秒（配置更短则使用更短值）。非流式重试沿用模型超时。当前页面会立即显示已请求停止；不强制终止线程。

只有完整成功的消息对和引用进入数据库。失败或停止的部分文本只保留在当前页面，切换会话/重启后不保留，也不参与后续模型上下文。临时检索结果不改变原有知识库依据约束。

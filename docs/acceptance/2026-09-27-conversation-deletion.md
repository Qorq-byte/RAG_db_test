# 会话选择删除验收

## 使用

在“问答”选择知识集合，点击会话框旁的“管理会话”。弹窗显示该集合全部已保存会话，包含标题、更新时间、编号和当前会话标记。默认不勾选，可单选、多选、全选、取消全选。点击“删除所选（数量）”后再次确认；确认框默认取消。

删除仅作用于选择的会话及其消息、引用快照。未选会话、其他集合和知识库资料保留。删除当前会话后清空问答显示与引用详情，进入新会话并保留未发送草稿；删除其他会话不改变当前对话。生成期间禁用管理入口并阻止直接调用。

## 数据处理

新增按集合校验的批量删除接口，在一个SQLite事务内执行；跨集合选择或中途数据库错误均整体回滚。重复ID去重，已不存在的ID幂等处理。使用现有外键级联，无数据库迁移。原有会话下拉框仍显示最近20条，管理弹窗读取全部记录。

读取失败显示提示；删除失败保留勾选以便重试。标题和确认内容以纯文本显示。深色主题的未勾选框使用随主题变化的清晰边框。

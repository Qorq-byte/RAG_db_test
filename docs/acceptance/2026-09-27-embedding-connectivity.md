# 嵌入模型连接与切换检查

## 范围与结论

用户要求检查嵌入模型能否连接其他模型服务，避免重现问答模型连接和保存问题。本次检查覆盖工厂路由、云端 HTTP、桌面测试与应用、凭据保存、重启、导入、检索和重建失败回滚。所有自动测试使用临时数据库、合成资料和测试密钥；未切换用户当前模型，未重建用户资料。

## 已修复

1. 云端适配器原来始终追加 `/embeddings`，填写完整接口地址会重复拼接。现在同时支持基础地址和完整接口地址，不擅自为第三方服务添加 `/v1`。
2. 云端响应原来忽略 `index`。现在有序号时核对其完整性并按输入顺序还原，防止资料和向量错配；无序号的兼容服务仍可按返回顺序处理。
3. 请求明确要求 `encoding_format=float`。拒绝非数值、布尔值、NaN/Infinity、无效序号、维度不一致或变化的向量。
4. HTTP 400/401/403/404/429 提供明确的修复方向。错误提示不拼接响应正文或密钥；桌面可显示安全提示。
5. 原来只更换嵌入 API Key 不改变模型指纹，应用按钮保持禁用。现在显示“保存密钥”，先用固定短文本验证，成功才更新凭据和当前运行时；不重建索引，不修改模型配置。测试失败保留原密钥和输入草稿。
6. 页面明确说明需要嵌入模型和 `/embeddings` 接口，聊天接口并不适用。

源码和测试已通过 `5c39dd2` 推送。产品改动限定在云端嵌入适配器、运行时密钥更新和模型设置页；另有 4 个测试文件覆盖这些链路。

## 验证证据

- 修复前新测试：14 项失败，复现完整地址、响应序号、数值校验、安全错误提示和密钥更新按钮问题。
- 修复后专项：**95 passed in 117.17s**，覆盖嵌入适配器、模型设置、桌面应用、全局重建和活动配置。
- 新增真实 HTTP 集成及模型设置服务组：**16 passed in 7.28s**；这组与上述专项有重叠，不相加作为用例总数。
- 实际启动隔离 HTTP 服务，使用不同 URL 路径、模型名和密钥，分别测试基础地址及完整接口地址。从云端模型 A 切换至 B（向量维度 3→4），真实导入、检索、配置重载和重启后检索均成功；另一个地址返回 404 时保留 B 的活动配置和原索引，后续检索成功。
- 桌面真实按钮链路：测试成功后密钥仍保留；重建切换后密钥保存在测试凭据库；重启后请求继续使用新目标。无效替换密钥不会覆盖有效密钥，成功替换后重启使用替换后的密钥，模型配置文件和向量命名空间不变。
- 本机真实 Ollama：`embeddinggemma:latest` 成功向量化两句固定测试文本，返回 **2 组、每组 768 维**。未发送知识库资料。

全量回归 **475 项全部通过，0 失败、0 跳过**：核心 331 项（275.19 秒）、桌面联合 61 项、其他 Qt 83 项。各组 XML 与完整收集清单逐项核对，0 遗漏、0 多余、0 重复，见[回归汇总](2026-09-27-embedding-connectivity-regression.json)。唯一警告来自故意构造重复 `manifest.json` 的备份负例。报告保存在 `.data/embedding-audit-*.xml`。

## 服务商文档与验证边界

通过 gstack browse 核对[硅基流动官方嵌入接口](https://docs.siliconflow.cn/docs/api/embeddings-post)：使用 Bearer 凭据、`POST /v1/embeddings`、字符串数组输入、`encoding_format=float`，响应包含嵌入向量和 `index`。文档核对日期：2026-09-27。旧文档路径已跳转并返回 404，本次引用有效新路径。

云端验证使用模拟响应及本机真实 HTTP 服务，**未使用用户的其他服务商账号进行付费云端调用**，因此不能声称所有服务商账号或任意模型均已实测。需要服务商提供 OpenAI 兼容嵌入接口，并使用其支持的嵌入模型、API Key 和正确地址；实际权限、额度、网络、输入限制需在目标账号上测试。原生非兼容接口不在当前适配范围。

此次不更改现有模型指纹计算方式，不迁移旧索引。历史模型生成质量和检索准确率不属于本次连接验证结论。

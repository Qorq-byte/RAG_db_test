# 导入任务与操作日志修复验收

## 问题与根因

用户确认：在“集合与资料”导入后，“最近任务”和“操作日志”仍显示暂无记录。

原实现只有目录导入创建任务，而且仅在目录结束时写入统计；单文件、文本、网页和仓库导入没有统一任务记录。部分 CLI 命令单独写入操作日志，桌面直接调用服务，绕过了这些日志代码。任务页面也未在重新进入时或导入过程中刷新。

## 已交付行为

- 五种桌面导入共用任务记录入口；开始时写入处理中任务及开始日志，结束时保存状态、结束时间和结束日志。目录、网页、仓库中的多个条目归入同一次任务。
- 每个条目完成后更新新增、更新、跳过、失败计数。单项失败、批次部分失败、模型初始化失败和远程抓取失败都会记录，异常不会使正常可写数据库中的任务一直处于处理中。
- 任务与日志在数据库中持久化，按当前集合显示最近 20 条。日志用任务编号关联，记录导入类型和统计，不保存资料正文、密钥、完整 URL 或异常原文。
- 导入结束（含失败）刷新页面；进入任务页立即刷新，可见期间每 2 秒刷新，隐藏时停止轮询。查询失败显示错误提示，避免把读取异常解释成暂无记录。
- 页面显示中文状态、本机时间以及完整四类计数；资料页反馈区区分新增、更新、全部跳过、部分失败、全部失败和空目录。

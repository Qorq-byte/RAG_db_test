# 微型索引读取恢复

Chroma 1.5.9、Python 3.11.15，固定96轮/384次首次查询：修改前5次 `Nothing found on disk`，短暂重复查询均失败，全部客户端退出后均恢复。故障涉及当前 Rust 系统的 HNSW 读取状态，并非仅 query API；get embeddings 也会失败。因此已丢弃精确距离回退方案，其同规模实验仍有12次失败，未提交。

应用修正：仅遇到该具体 InternalError 时，启动独立读取进程（30秒超时、最多一次），按同一集合存储ID、筛选、向量及查询参数读取。新进程创建自己的客户端并回放持久记录；不关闭其他客户端，不改配置或索引阈值，无睡眠循环。新读取也失败时保留原错误，发布及清理继续拒绝不安全操作。正常路径没有进程开销。维护预检的 get/query 同样适用。

最终固定96轮对照：384次查询全部成功，6次通过隔离读取恢复；报告 `.data/completion-reader-final.json`。中间一次运行期间更新了子进程协议，导致父子版本不一致的2次失败；停止修改后重跑上述固定规模，未混用为成功证据。

定向回归86项通过（85.54秒），覆盖客户端共享、跨进程检索、原子发布、取消及故障保护、旧索引清理，以及新增的隔离读取/筛选/原错误保留用例。

这是应用层对已复现异常的恢复方案，不宣称上游 Rust 根因已经修复。官方历史[问题4212](https://github.com/chroma-core/chroma/issues/4212)关联[修复4224](https://github.com/chroma-core/chroma/pull/4224)，但描述版本为1.0.2，不能据此认定本机1.5.9异常是同一根因。

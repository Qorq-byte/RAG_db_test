# 全库备份恢复验收

入口：CLI `ragdb backup create/verify/restore`；桌面“任务与诊断 → 备份与恢复”。恢复配置可通过 `ragdb-gui --config PATH` 打开。

备份包括SQLite全部业务表及FTS、活动模型、所有Chroma命名空间的向量/正文/元数据/距离配置，以及不含密钥的有效应用配置。不复制库外原文件、模型缓存、系统凭据和环境文件。库外文件的来源定位保留，已入库正文可直接恢复和检索。

创建期间持有索引独占门禁及SQLite写锁，使用SQLite backup一致快照与分页逻辑向量导出；ZIP清单附逐文件SHA256。恢复先在同父目录的暂存区校验文件集合、重复路径、摘要、SQLite完整性/外键和配置，恢复完成后才发布新目录。清除快照中的运行门禁，保留业务数据和原库；配置指向新目录。新目录必须不存在。

验证：备份及桌面/启动回归30项通过（6.38秒）；补充业务完整往返后备份专项8项通过（4.53秒）。覆盖导出密钥排除、集合/资料/切片/FTS/对话/学习产物/活动模型逐表一致、恢复后关键词/向量检索、并发写门禁拒绝、原库不变、损坏/越界/重复ZIP拒绝、CLI校验恢复。

用户原有测试修改和前端设计文件未纳入本步骤。测试全部使用隔离合成库。

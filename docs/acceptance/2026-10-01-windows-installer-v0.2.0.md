# Windows 安装包 v0.2.0 验收

本版将当前源码中的邮箱注册与登录、账号独立资料目录、个人资料菜单、模型入口、密码找回和永久注销带入 Windows x64 安装版，同时包含 v0.1.1 之后的问答气泡、侧栏计数及复杂文档离线评估。保留原正式 AppId 供原位升级；旧版未归属账号的知识库保持原状，不自动归给新账号。

## 配置与隐私

安装版 `packaging/launcher.py` 内置项目的 Supabase **公开** URL 和 publishable key。首次安装写入本机配置；从旧版升级且 `[auth]` 两项均为空时，仅在进程中提供相同默认值，不改写旧配置。用户自定义认证项目或环境变量保持优先。`service_role`、`sb_secret_`、SMTP 凭据、模型 API Key 均未放入客户端。冻结文件清单未见仓库根目录的 `config.toml`、`.env`、SQLite 库或备份 ZIP；包内 CA 证书属于依赖的公开信任根。

安装版公开认证客户端在构建后通过 `GET /auth/v1/settings` 连通检查。注册邮件投递、在线登录和真实账号永久注销此前已使用单个测试账号从源码桌面端验收；本轮没有再次创建或删除真实账号，也没有把离线冒烟写成所有邮箱服务商验证。

## 构建与验证

- `uv lock --check --offline` 通过；使用 Python 3.11.15、PyInstaller 6.22.3 和 Inno Setup 6.7.3，从固定锁文件构建。
- 完整 `pytest -q`：**510 passed**，耗时 742.02 秒；1 条预期警告来自备份测试刻意创建重复 `manifest.json`。
- `dist/RAGDB/RAGDB-CLI.exe --self-test` 通过：依赖导入、离线资源、固定检索评估、隔离索引读取、备份恢复。
- 使用不同的测试 AppId 从同一冻结目录编译隔离安装程序，安装到项目 `.data/release-020-smoke/installed`。安装后 CLI 返回 `0.2.0`，首次生成的配置含公开认证项目，GUI 无界面启动正常退出，卸载后合成用户资料仍保留。测试 AppId 与安装目录均不触碰正式应用登记或用户数据。
- README 演示为 75 秒、1280×880、12 fps H.264 视频；录制脚本验证隔离库中的导入、检索、会话保存和导航，画面人工抽帧检查。认证交接和模型回答是模拟内容。

# RAGDB 演示素材

[返回项目首页](../../README.md) · [观看视频](ragdb-tour.mp4)

## 内容与边界

`ragdb-tour.mp4` 为 60 秒、1280×880、12 fps、H.264 / yuv420p、无音轨的中文字幕演示。`ragdb-tour-poster.png` 是同一次录制中的问答画面。

画面直接来自 v0.1.1 基础上当前源码的 Qt 控件渲染（含 `2bae7d7` 顶部问答状态修正，未重发安装包），展示欢迎动画、进入工作台、建立集合、导入文本、检索、流式问答、任务记录与概览。操作由脚本驱动；进入欢迎页末尾使用与 End 键相同的快捷入口。录制不是完整人工鼠标教学，也不是响应速度测评。

- 数据来自脚本内的虚构集合和公开演示文本；不读取用户资料或已有数据库。
- 文本解析、SQLite / Chroma 写入、检索、任务记录和问答持久化使用真实应用服务。
- 向量使用项目已有的离线 bigram 实现；聊天输出由 `DemoChat` 预设并逐段发送，不调用真实大模型。
- 每帧底部均标注“虚构资料 / 离线演示向量 / 模拟模型回答”。
- 不录制桌面或其他窗口，不读取本机 `.env`、个人配置和系统凭据；使用临时数据库与独立外观设置。
- 编码移除输入元数据，无麦克风或系统音频。模型设置页不进入录制。

## 复现方法

先安装项目依赖和 FFmpeg，确保 `ffmpeg` 在 PATH 中，然后在项目根目录运行：

```powershell
uv sync --frozen
uv run python scripts/record_demo.py
```

录制脚本会在当前子进程清除 `RAGDB_` 环境配置，切换到临时目录，使用独立知识库。输出会覆盖本目录同名演示文件；不会改动用户实际知识库。临时目录退出时清理，Windows 如仍有文件句柄占用，可能留下一份仅含合成内容的临时目录。

脚本在完成前检查导入资料数、检索结果和已保存会话数。字幕与画面仍需人工检查后再发布。视频不是自动测试或真实供应商兼容性的替代品。

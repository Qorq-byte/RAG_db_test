# 桌面端实际体验与交互完善实施计划

落实已批准的 `2026-09-23-desktop-experience-polish-design.md`。每一阶段完成定向测试后单独提交并推送；所有阶段完成后运行完整回归。

## 步骤 1：导航与窗口布局

- 扩展 `ThemeManager`，集中读取、归一化和保存侧栏宽度、折叠偏好与详情栏开合偏好。
- 扩展 `SidebarWidget`：实现 160–400px 的拖拽手柄、宽度变更信号、持久化前的用户意图信号及减少动效下的即时状态切换。
- 更新 `MainWindow`：区分用户偏好与小窗口临时覆盖，窗口恢复时还原偏好；详情栏状态同样遵循该规则。
- 测试设置值归一化、拖拽边界、状态恢复和窄窗收起/恢复。

## 步骤 2：统一后台操作反馈

- 提取桌面页可复用的异步操作状态控制器，统一任务引用保留、触发控件禁用、完成/失败恢复与集合代次校验。
- 将集合导入操作迁移到该控制器；为检索、问答和学习产物的提交入口接入相同生命周期，不改变现有服务调用。
- 以页面内状态徽标或消息区显示成功摘要和可操作失败原因；普通后台失败不再产生阻断对话框。
- 测试重复提交防护、成功/失败后的恢复、过期结果丢弃与仅刷新当前上下文。

## 步骤 3：键盘与可访问性

- 在 `MainWindow` 注册 `Ctrl+1` 至 `Ctrl+6`、`Ctrl+B` 和 Escape 优先级行为。
- 为导航、拖拽手柄、详情栏关闭及主要页面操作添加可访问名称、描述、工具提示与焦点策略。
- 通过主题样式补足 `:focus`、禁用和状态文字对比；确保隐藏面板不在焦点链。
- 测试快捷键、Escape、焦点可达性与隐藏控件焦点策略。

## 步骤 4：验收

- 运行桌面定向测试和 `uv run pytest`。
- 用 `RAGDB_GUI_TEST_EXIT_MS` 进行无头启动检查；在 Windows 桌面手工确认 1280×800 与 1024×640 布局、拖拽和快捷键。
- 更新 README 的桌面工作台说明（如新快捷键或行为需要用户知悉）。

# PySide6 桌面界面重构实施计划

## 步骤 1：主题系统与公共组件

实现浅色、深色、跟随系统主题和减少动效设置；建立 QSS 令牌、`PageShell`、`StatCard`、`StatusBadge`、`EmptyState` 与 `DetailPanel`。覆盖设置持久化和组件状态测试。

## 步骤 2：导航栏、顶部栏与响应式主窗口

以原生 Qt 实现分组、图标、活动指示、悬停背景和折叠动画；加入顶部栏和可折叠详情栏。在 1280×800 与 1024×640 验证布局。

## 步骤 3：六个业务页面重构

重构概览、集合与资料、检索、问答、学习产物、任务与诊断页面；统一导入菜单、结果卡、消息流、参数面板、标签页及页面内加载/空/错误状态。

## 步骤 4：验收与文档

覆盖主题、导航、集合切换、详情栏和后台过期结果测试；运行全量测试与真实 `ragdb-gui` 启动检查，更新 README。每一步测试、提交并推送。

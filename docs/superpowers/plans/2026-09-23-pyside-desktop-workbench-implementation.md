# PySide6 桌面工作台实施计划

## 步骤 1：运行时工厂、Qt 基础设施与主窗口骨架

加入 PySide6 依赖和 `ragdb-gui` 入口；从 CLI 抽取可共享运行时装配；实现后台任务执行器、全局集合上下文、三栏主窗口与导航空页面。覆盖启动、导航、异常信号和过期任务结果测试。

## 步骤 2：概览、集合、资料与导入

实现集合 CRUD、全局切换、资料列表与删除，以及文件、目录、文本、网页和 GitHub 导入。所有阻塞操作进入后台，显示进度/结果并确认破坏性操作。

## 步骤 3：检索、问答与学习产物

接入检索筛选和来源详情；实现历史会话与消息流；实现五类学习内容生成和产物管理。验证集合隔离、引用定位和后台错误呈现。

## 步骤 4：任务、日志、诊断与验收

实现任务、操作日志和 doctor 页面，完善空/加载/失败状态；运行 Qt 定向测试、关键集成路径、全量回归及 `uv run ragdb-gui` 启动检查。每一步测试、提交并推送。

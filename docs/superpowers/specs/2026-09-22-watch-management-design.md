# 监听与索引管理设计

## 目标

提供对本地资料目录的前台持续监听，以及针对指定集合的明确重建入口。用户运行 `ragdb watch start PATH --collection NAME` 后在当前终端观察同步结果，按 `Ctrl+C` 正常停止。

## 已选方案

采用 Watchdog 前台观察器，不创建后台进程、PID 文件或跨终端状态。文件事件先经短时去抖合并：新增和修改交给既有 `LocalIngestionService`；删除移除资料、关键词和向量代次；移动按内容哈希尽可能识别为路径变化。

`watch status` 与 `watch stop` 明确说明本模式由当前终端管理。`reindex --collection` 仅针对显式集合，逐资料重新解析与索引，失败隔离并输出汇总。

## 安全与验证

- 仅监听用户给定且存在的目录，复用当前允许扩展名、忽略目录和大小限制。
- 去抖不跨越不同路径；停止后不得继续写入索引。
- 删除仅操作由该资料 URI 关联的资料及其索引。
- 测试以临时目录和可控观察器覆盖新增、修改、移动、删除、停止与重建。

## 提交边界

1. 监听基础设施、事件去抖和同步测试。
2. CLI 前台监听、删除同步与可读状态。
3. 明确集合的 `reindex`、回归和文档记录。

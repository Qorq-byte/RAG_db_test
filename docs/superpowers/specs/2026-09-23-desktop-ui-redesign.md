# PySide6 桌面界面重构设计

## 目标与设计来源

基于 `前端设计/导航栏.txt` 的分组导航、细线刻度、活动指示、滑动悬停背景和折叠行为，重构现有 PySide6 桌面工作台。保留原生 Qt 技术栈，不引入 React、shadcn、Tailwind 或 WebEngine。界面应体现项目的核心特征：多集合知识管理、可追溯混合检索、受证据约束的问答、学习内容生成和透明的任务诊断。

## 视觉系统

应用支持浅色、深色和跟随系统三种主题。`ThemeManager` 使用统一令牌生成 QSS，令牌包括窗口背景、侧栏、面板、浮层、主/次文字、边框、青蓝强调色、成功、警告和危险色。默认跟随系统，并持久化主题和“减少动效”设置。

字体优先使用 Windows 系统中文 UI 字体。标题、正文、辅助信息和等宽技术信息形成四级层次。圆角、间距、边框和阴影保持克制，避免默认 Qt 控件拼接感。

动效持续 120–220ms。开启“减少动效”时，折叠和状态切换立即完成，仅保留必要反馈。

## 主窗口结构

主窗口由四个区域构成：

1. 左侧 `SidebarWidget`：展开宽度约 236px，折叠宽度 68px。
2. 顶部 `TopBar`：当前页面、集合选择、后台任务状态和主题切换。
3. 中央页面工作区：承载六个业务页面。
4. 右侧 `DetailPanel`：可折叠的资料、评分和引用详情。

窗口以 1280×800 为基准，1024×640 仍需可用。窄窗口优先折叠侧栏和详情栏。

## 导航栏

导航分为三组：

- 知识库：概览、集合与资料、检索。
- 学习：问答、学习产物。
- 系统：任务与诊断。

侧栏顶部显示 `RAG DB` 标识、当前集合状态和折叠按钮。每项使用 Lucide 风格的简洁线性图标；项目内通过 Qt 自绘或标准图标保持一致，不使用图片资源。

活动项显示青蓝色短横指示条。悬停背景在项目之间平滑移动，文字轻微右移，非活动项目适度降低透明度。折叠后仅保留图标、活动指示、工具提示和展开按钮。`SidebarWidget` 只发出页面选择信号，不持有业务状态。

## 页面布局

### 概览

顶部显示欢迎信息和当前集合。四张统计卡展示资料、会话、学习产物和最近任务；下方展示最近活动与导入、检索、问答、生成快捷操作。

### 集合与资料

左侧为集合列表，中间为资料表格。顶部统一“导入”菜单承载文件、目录、文本、网页和 GitHub，避免平铺大量按钮。资料状态、类型和更新时间使用清晰列与状态徽标。

### 检索

顶部为主搜索框和可折叠筛选区。结果以卡片呈现标题、摘要、召回路径和核心评分；选中卡片后在右侧显示完整原文、URI、精确位置和全部评分。

### 问答

左侧为历史会话，中间为消息流，底部固定输入区。回答中的来源编号可操作，并更新右侧详情栏。等待模型时禁用重复发送并显示后台状态。

### 学习产物

左侧为历史产物，中间为 Markdown 正文。顶部“生成”按钮打开参数面板，选择类型、主题和可选资料范围；引用在右侧统一展示。

### 任务与诊断

任务、操作日志、环境诊断使用三个标签页。成功、警告、失败采用统一 `StatusBadge`；错误信息包含可执行的修复建议。

## 公共组件与状态

- `ThemeManager`：主题检测、切换、令牌和设置持久化。
- `SidebarWidget`：分组导航、折叠、活动/悬停动画。
- `TopBar`：页面标题、集合、任务状态和主题操作。
- `DetailPanel`：来源、位置、评分和引用详情。
- `PageShell`：标题、说明、操作区及加载、空、失败状态。
- `StatCard`、`ResultCard`、`StatusBadge`、`EmptyState`：统一视觉组件。

SQLite 快速读取可同步执行；导入、检索、模型调用和诊断继续使用后台任务。错误优先显示在页面状态区，破坏性操作才使用确认对话框。切换集合后，带旧上下文令牌的后台结果不得更新界面。

## 测试与验收

- 覆盖浅色、深色、跟随系统和减少动效设置。
- 覆盖导航分组、折叠/展开、页面切换、活动状态和工具提示。
- 覆盖顶部集合状态、详情栏开合及集合切换后的过期结果丢弃。
- 六个页面覆盖加载、空、正常和失败状态。
- 在 1280×800 与 1024×640 下检查可用性。
- 保持全量 Python 测试通过，并执行 `ragdb-gui` 真实启动检查。
- 每个可验证实施步骤单独测试、提交并推送 GitHub。

本次仅重构桌面展示层和界面控制边界，不改变导入、检索、问答、生成、存储和 CLI 的业务语义。

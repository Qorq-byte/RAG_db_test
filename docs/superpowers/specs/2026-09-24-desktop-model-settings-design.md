# 桌面端模型设置设计

## 目标

让用户无需手工编辑配置文件，即可在 PySide6 工作台中配置问答/学习生成模型与嵌入模型，并验证连接。更换嵌入模型时，保证所有集合在索引切换完成前继续使用旧模型和旧向量。

## 当前基线

- 问答与学习产物生成共用 `[chat]` 配置；支持 Ollama 和 OpenAI 兼容聊天接口。
- 嵌入支持本地 Sentence Transformers 与 OpenAI 兼容接口。
- 云端密钥从环境变量或 `.env` 加载，TOML 密钥被有意忽略。
- 桌面端目前只有“任务与诊断”系统页，没有模型设置页。
- `reindex` 通过重新导入源文件，仅处理 `file://` 资料。SQLite 已保存所有当前切片文本，因此可直接为任意来源重建向量，包括网页、GitHub 仓库和手动文本。
- Chroma 集合使用固定向量维数。同一集合不能安全地同时写入不同维数的旧/新向量，因此嵌入模型切换不能直接覆盖当前 Chroma 集合。

## 用户体验

在系统导航组新增“模型设置”页面，分为“问答与生成”和“嵌入”两个独立卡片/分区。每区显示当前生效配置及配置来源；若环境变量覆盖字段，则标记为“由环境变量管理”并禁用相应输入，说明可修改的环境变量名。

问答/生成区支持：

- 提供商：本地 Ollama、云端 OpenAI 兼容服务。
- 模型名称、服务地址和超时；云端另有密码输入框。
- Ollama 可刷新本机已安装模型并选择，也允许手动输入名称。
- “测试连接”发送一条固定的最小测试提示，显示成功或可读错误。云端测试前明确提示服务可能计费。
- 保存后立即应用于问答和学习产物生成，不改变既有会话或学习产物。

嵌入区支持：

- 提供商：本地 Sentence Transformers、云端 OpenAI 兼容服务。
- 模型名称、服务地址、超时和批大小；云端另有密码输入框。
- “测试连接”仅嵌入固定短文本并检查向量有效性，不修改知识库索引。首次测试本地模型可能需要下载模型，界面显示运行状态。
- 更换已在用的嵌入配置后显示“需要重建 N 个集合”，提供“重建并切换”操作。操作期间展示整体与当前集合进度、成功/失败详情，并可取消尚未发布的重建。
- 新索引完成并验证后才切换全局生效模型。任一集合重建失败时保留原配置与旧索引，不进入新模型状态。

## 方案与取舍

采用一个独立的模型设置页面，分离问答/生成与嵌入配置。将全部字段塞进“任务与诊断”会让常用配置难以发现；首启向导不适用于用户之后更换模型；继续要求编辑 TOML/环境变量无法满足直观配置的目标。

非敏感问答配置和待应用的嵌入配置写入应用当前使用的 TOML 配置文件，并通过原有设置加载路径应用。云端密钥写入 Windows 系统凭据存储（通过系统 keyring 接口）；密钥不进入 TOML、操作日志、错误文本或普通 UI 标签。环境变量与 `.env` 继续具有更高优先级；页面明确指出受覆盖字段及覆盖来源，避免用户误以为保存后已生效。

## 嵌入索引切换

重建只使用 SQLite 中每个资料当前有效代次的切片文本，不重新解析源文件、不重分块，也不重建 FTS 索引。适用于本地文件、网页、公开仓库和手动文本。

为新嵌入配置创建独立的 Chroma 向量命名空间，命名或元数据关联一个不含密钥的稳定配置指纹。SQLite 持久化活动嵌入配置及其指纹，作为当前向量索引的权威状态；TOML 保存用户选择的配置。首次建库时从 TOML 初始化活动配置。逐集合、逐资料将新向量写入暂存命名空间；旧命名空间保持可检索。所有集合均成功后，在 SQLite 事务中发布新活动配置指纹及来源嵌入信息，再由运行时切换到新的向量命名空间。随后同步 TOML；若进程在同步前退出，启动时以 SQLite 活动配置为准并修复 TOML。旧命名空间暂时保留，确保发布后可恢复；清理旧索引作为后续显式维护能力，不在本功能自动删除。

若暂存阶段失败或取消，不改变活动指纹、不更新来源状态，并清理本次尚未发布的暂存命名空间。进程重启后仍以数据库中发布的活动指纹为准；未完成的暂存索引在下次打开页面时提示清理后重试。空知识库只需验证新配置并原子保存，不创建向量命名空间。

## 架构边界

- `ModelSettingsPage` 负责表单、字段校验、测试结果、重建确认和进度呈现。
- 模型配置应用服务封装加载/保存、环境变量覆盖判断、密钥存储及测试连接；UI 不直接解析 TOML 或调用模型 SDK。
- 云端密钥按提供商及配置指纹保存在系统凭据存储中，使活动索引与待重建配置各自能取回对应密钥；界面不读取并回显密钥明文。
- Chat/Ollama 适配器增加模型枚举能力；连接测试复用现有 `ChatModel` 和 `EmbeddingProvider` 适配器。
- 新增嵌入重建应用服务，读取当前 SQLite 切片，以可取消的后台任务逐批嵌入及写入暂存向量命名空间，并在全部集合完成后发布。
- `ApplicationRuntime` 初始化数据库后读取活动嵌入配置；`SearchService` 使用其指纹解析向量命名空间。新安装及旧版数据库将现有默认命名空间兼容迁移为初始活动命名空间。
- SQLite 重建状态作为跨 CLI/桌面的导入闸门，避免其它进程在全局向量重建期间写入新资料。
- UI 中的耗时模型测试和重建都在后台执行，切换页面不阻塞主线程。

## 错误与安全规则

- 配置字段在保存前按现有 Pydantic 模型校验；提供商切换仅影响所选配置区。
- 密钥输入默认掩码；读取已存密钥仅显示“已配置”，不回显原值。保存空白值表示保留现有密钥；通过单独清除操作移除凭据。
- 测试连接和嵌入重建的异常不得包含请求头或密钥；日志只记录提供商、模型名、集合/资料标识和结果。
- 保存问答模型设置不触发嵌入重建。只有嵌入提供商、模型或服务地址等影响向量兼容性的字段变化才要求全局重建。
- 全局重建未完整成功前，搜索、问答和导入仍使用旧活动嵌入配置；重建期间阻止新的资料导入，并说明完成后可重试，避免漏入暂存索引。

## 验收

- 桌面用户可在界面配置 Ollama/云端问答模型与本地/云端嵌入模型，保存后重启仍生效。
- 覆盖环境变量接管提示、密钥写入系统凭据存储、密钥不回显和 TOML 不含密钥。
- Chat 与 embedding 测试分别覆盖成功、无效密钥、服务不可达和响应格式错误；本地模型缺失时显示明确安装/拉取建议。
- 索引切换覆盖多集合及本地文件、网页、GitHub、手动文本切片；新旧命名空间不同维数时互不冲突。
- 注入嵌入失败、取消及发布失败，验证旧活动模型仍可搜索且 SQLite 来源代次与旧向量保持一致；全成功后验证新模型检索可用。
- 桌面自动化覆盖页面可发现性、模型表单校验、后台操作反馈及重启恢复；全量回归通过。

## 不在本次范围

- 引入 LangChain 或重写现有 RAG 链路。
- 自动下载/安装 Ollama 或自动拉取聊天模型；界面只检测并选择 Ollama 已安装模型，缺失时说明如何安装。
- 更改知识库分块配置、重排模型、OCR、向量库或生成提示词。
- 自动删除旧向量索引；由后续显式清理流程处理。

## 必须保留的参考交互

- 20 张原图离线打包，卡片 60×85，圆角、阴影、正面 10% 黑色遮罩；悬停透视翻转，背面 View / Details。
- 启动散落；500ms 开始聚成横列，2500ms 开始展开圆环。卡片位置采用 stiffness=40、damping=15 的弹簧过渡。
- 虚拟滚动范围 0–3000：0–600 圆环变形成底部弧带，600–3000 弧带向左转动，图片沿弧线依次从下边界移出。上滚可逆，范围有限，不无限循环。
- 原始圆环/弧带半径、角度、宽度小于 768 时的布局与放大比例逐项移植；视口裁切离场图片。
- 鼠标横向位置映射 ±100px 视差，仅参与弧带部分；视差和滚动使用弹簧平滑。滚轮角度与触控板像素增量互斥处理，支持触摸滑动。
- 保留 `#FAFAFA` 背景、The future is built on AI.、SCROLL TO EXPLORE、Explore Our Vision 及原说明文字；中心内容淡出、模糊与位移，顶部弧带内容淡入。
- 图片的实际绘制边界全部移出视口后，再向下滚动一次，中央立即显示欢迎按钮；不等待弹簧收敛，也不额外淡入；鼠标移动不能让按钮消失，反向滚动可以返回探索。点击后才进入导航。

## 桌面体验与生命周期

方向键、PageUp/PageDown 可探索；Home 返回开头，End / Esc 跳到最后但不直接进入。减少动效偏好直接呈现最后状态。按钮支持 Enter / Space。最小窗口 640×480，支持 DPI 和缩放；欢迎页维持参考浅色设计，工作台继续使用用户主题。

QGraphicsView + Qt 弹簧计时器和本地图片，无 React / WebEngine。动画稳定或窗口隐藏时停止计时器；再次显示恢复。装饰文字不截获鼠标事件。点击后锁定滚动、防止重复初始化；失败恢复同一按钮。runtime 在后台初始化，主线程创建导航窗口，保留大小与最大化状态；不提前访问用户知识库。

# 桌面启动欢迎页

## 用户指定的设计与交互

依据 `前端设计/用户界面进入界面.txt` 的图片卡片动效设计。用户已确定后续以 Windows 桌面软件呈现，本次明确要求启动时先显示动画，动画结束后中央出现“欢迎使用RAG系统”按钮，点击后进入已有导航主界面。

采用 PySide6 原生移植：20 张本地图片依次从散落位置聚成横列，再展开为圆环；自动播放约 4 秒，圆环稳定后淡入中央内容及按钮。不要求滚轮才能显示入口。保留卡片悬停翻转；原示例滚动成底部弧带的营销页面交互不属于此启动流程。

不引入 React、Tailwind、浏览器或 WebEngine。备选的嵌入网页会引入第二套 UI 运行时；静态开屏无法实现指定动效，因此选择 QGraphicsView + Qt 动画。

## 视觉约定

- 浅色画布 `#FAFAFA`，主文字 `#18202B`，次文字 `#687386`，按钮 `#0F8AA6`，按钮文字 `#FFFFFF`，细线 `#DCE2EA`。深色模式复用工作台已有色板。
- 中央展示“让知识，产生连接。”与确切按钮文案“欢迎使用RAG系统”；按钮居于窗口中心。字体沿用 Microsoft YaHei UI / Segoe UI，标题 30px、正文 13px、按钮 16px。
- 页首显示 RAG 标识和“个人知识工作台”；页脚保持简短产品说明。视觉主体是参考文件里的摄影卡片圆环，不增加数据统计或功能卡片。
- 圆环半径和卡片尺寸根据窗口可用空间缩放；最小窗口 640×480。支持高 DPI、主题切换及系统关闭按钮。
- 图片从参考文件中的 20 个地址取用并本地打包，运行时不发送图片网络请求；缺失图片使用绘制卡片兜底，不阻塞入口。

## 生命周期

启动先显示 WelcomeWindow，不创建知识库 runtime 或 MainWindow。用户进入后由后台任务初始化 runtime，主线程创建 MainWindow；先显示主界面，再关闭欢迎窗口，保持位置、大小与最大化状态。防止重复点击。

初始化失败时留在欢迎页，显示不含底层异常敏感信息的错误提示，恢复同一按钮以供重试。后台初始化尚未结束时关闭窗口给出等待提示，避免遗留工作线程。未开始初始化时可直接关闭。

动画由窗口拥有，关闭/隐藏时停止，避免隐藏窗口持续绘制。Esc 或“跳过动画”只跳到最终欢迎状态，不绕过欢迎按钮。减少动效模式直接显示最终状态，键盘 Tab/Enter/Space 可进入。每次启动播放一次，主界面内部导航不重播。

## 验证与交付

验证动画前按钮不可进入、动画结束仍需点击、跳过与减少动效、重复点击、初始化失败重试、关闭与隐藏停止动画、窗口尺寸变化及进入后导航可用。使用隔离配置进行 Windows 原生截图检查和启动冒烟；不改动用户知识库或设计原文件。

沿用每步独立提交推送的约定，工作分支 `codex/desktop-welcome`。主线合并另按明确授权执行。

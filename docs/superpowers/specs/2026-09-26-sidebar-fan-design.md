# 侧边栏底部扇形卡片设计

## 用户要求与参考

按 `前端设计/侧边栏底部ui.txt` 的 card-fan-carousel 构建底部 UI，填充导航下方空白；用户可添加或移除整个底部组件。继续 PySide6 原生桌面，沿用参考的十张图片及全部主要交互，不引入 React / GSAP / WebEngine。

## 原生移植约定

- 十张指定图片离线打包，一次最多显示七张。按原数组的 ±21° / ±14° / ±7° 扇形旋转、缩放、位置和层级组织；中央卡片在最上层。
- 初次显示从下方小尺寸透明状态错峰弹性入场，200ms 起步、每张间隔 60ms、单张 1.2s。
- 悬停卡片上移并放大 1.08 倍，其余卡片按距离向两边让位并微转；离开区域 50ms 后弹性复位。过渡中可更新悬停目标。
- 按用户后续要求改为鼠标滚轮下滚下一张、上滚上一张，支持触控板；移除左右箭头，保留十个位置圆点和滚动提示。循环切换时，已有卡片 500ms 过渡、新卡片从对应侧 600ms 入场、旧卡片向另一侧 400ms 离场；切换期间防重复操作。支持聚焦画布后的左右方向键。
- 用户给定片段没有 fan-card / fan-layout 尺寸样式，因此补齐适合侧边栏的 160×224 设计卡片；按窄布局的 .28 水平系数和高度预算，整体等比适配 160–400px 导航栏，保留原始扇形关系及悬停让位。透明画布沿用工作台深浅主题。
- 组件占用导航下方可分配空间，最大 300px，不挤压导航项。可用高度不足 112px 时停止并收起轮播，显示“增大窗口以查看卡片”；增大后自动恢复。

## 添加、移除与状态

默认显示。底部始终保留“移除底部卡片”或“添加底部卡片”按钮；移除不删除图片，也不影响欢迎页或知识库。保存到 QSettings 的 layout/sidebar_footer_visible，重启恢复。

导航折叠时暂时隐藏组件，偏好不变；折叠状态仍保留带提示和无障碍名称的加减按钮。主题或减少动效设置立即生效。隐藏、折叠或移除停止动画与离开延迟定时器；稳定状态不占用动画计时器。示例图片没有 linkUrl，不添加虚假的点击跳转。

## 验证与交付

组件测试覆盖错峰入场、七卡窗口、循环回绕、防连点、真实鼠标悬停、键盘、减少动效、隐藏停止、缺图及少量图片、窄宽/短高布局。MainWindow 验证移除/恢复偏好、重启和折叠、已有导航。Windows 原生窗口截图复核深浅主题和实际操作。

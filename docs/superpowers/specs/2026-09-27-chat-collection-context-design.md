# 问答集合提示与切换

用户已同意在输入框上方显示“当前提问集合：XXX”，并增加“切换集合”入口。沿用 brainstorming 流程中已确认的这一方案，不再重复请求批准。

在问答输入区内增加醒目的集合名称与切换按钮，未选集合时显示“当前提问集合：未选择”，按钮为“选择集合”。集合名使用纯文本，可换行并提供完整名称提示。弹窗选择已有集合，默认定位当前集合；取消不改变任何状态。没有集合时引导至“集合与资料”创建。

用户后续明确纠正：切换集合不得切换会话，只有主动选择会话或新建才切换。集合切换仍同步顶部、侧栏、资料列表、检索、问答和任务页，但保留当前会话ID、历史消息、引用和草稿。后续问题（含重试）使用当前所选集合检索，成功回答追加至同一会话。历史按初次创建时的集合归档，不搬动旧记录；每条回答保留自己的引用。生成期间禁用集合切换，停止请求尚未完成时仍不能切换。

实施步骤：增加提示和切换事件；接入主窗口选择器及按UUID恢复资料列表选择；验证显示集合与实际请求集合一致，测试取消、无集合、读取失败、集合消失、生成中阻止切换和跨页同步；检查原生深浅主题与长名称。分步推送源码，不构建或发布安装包。
